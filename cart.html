📖 How does the 0/1 Knapsack Algorithm work here?
  1. Items: The 8 medicines in the catalogue. Each has a price (weight) and a healthPriority score (value).
  2. DP Table: A 2D table dp[i][w] is built where i = item index and w = budget. dp[i][w] stores the maximum health value achievable using the first i items within budget w.
  3. Recurrence: If price[i] > w → skip item: dp[i][w] = dp[i-1][w]. Otherwise → take max of skipping or including: dp[i][w] = max(dp[i-1][w], dp[i-1][w-price[i]] + value[i]).
  4. Backtracking: Starting from dp[n][budget], trace back through the table to recover which items were selected.
  5. Time Complexity: O(n × W), where n = 8 products and W = your budget.
